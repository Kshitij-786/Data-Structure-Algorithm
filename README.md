## 📌 Overview

This repository contains my **Data Structures and Algorithms (DSA)** practice questions and solutions, organized in a structured manner from basic concepts to more advanced problems.

The main purpose of this repository is to strengthen problem-solving skills, understand important data structures and algorithms, and maintain a structured collection of DSA programs for regular practice and revision.

## 📊 Complexity Analysis

For algorithmic problems, **time complexity** and **space complexity** are important considerations.

Common complexities include:

```text
O(1)        Constant
O(log n)    Logarithmic
O(n)        Linear
O(n log n)  Linearithmic
O(n²)       Quadratic
O(2ⁿ)       Exponential
```

Understanding complexity helps compare different approaches and select more efficient solutions.
